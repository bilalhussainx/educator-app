  📋 How to Get Calendly API Keys:

  1. Personal Access Token (Development):
    - Go to Calendly → Settings → Developer → Generate new token
  2. OAuth App (Production):
    - Visit https://developer.calendly.com/ → Create an App
    - Get Client ID, Client Secret, and Webhook signing key
  3. Environment Variables:
  CALENDLY_CLIENT_ID=your_client_id_here
  CALENDLY_CLIENT_SECRET=your_client_secret_here
  CALENDLY_WEBHOOK_SECRET=your_webhook_signing_key_here
