# Portfolio Images

Add your 6 portfolio images here:

1. `educators-edge-dashboard.jpg` - Screenshot of the main dashboard
2. `educators-edge-ide.jpg` - Screenshot of the code editor
3. `educators-edge-video.jpg` - Screenshot of video session
4. `synergypost.jpg` - SynergyPost screenshot
5. `architecture.jpg` - Architecture diagram or system design
6. `leetcode-enrichment.jpg` - LeetCode features screenshot

## Image Specifications

- **Format:** JPG or PNG
- **Recommended size:** 1920x1080 (16:9 aspect ratio)
- **File size:** Under 1MB each for best performance

## Don't have images yet?

The portfolio will display colored placeholder planes until you add images. You can:

1. Take screenshots of your Educators Edge app
2. Create mockups in Figma/Canva
3. Use code screenshots from Carbon.now.sh
4. Add architecture diagrams

## Adding More Images

To add more than 6 images, edit `src/pages/DeveloperPortfolio3D.tsx` and update the `portfolioImages` array around line 24.
